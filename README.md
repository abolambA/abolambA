## 👤 Who I Am

I'm **Mohamad Nihad Alsufe** — a 16-year-old entrepreneur, full-stack developer, and competitive speedcuber based in **Sharjah, UAE** 🇦🇪, originally from **Homs, Syria** 🇸🇾.

At an age when most people are figuring out what they want to do, I've already built **two operating companies**, led a school tech team to **national competition wins**, shipped AI products used by real users, won a **UAE Ministry of Education national championship**, placed **2nd at the Safe AI Cup 2026**, and earned a **Gold Medal at Innovation Nation 2026** — competing at the Arab regional level.

I build across the full stack: mobile apps in **Flutter**, web platforms in **Next.js** and **React**, AI automation pipelines with **LangChain** and **n8n**, backends in **FastAPI** and **NestJS**, cloud infrastructure on **AWS** and **GCP**, and Shopify themes in **Liquid**. I'm also a **GCAA-licensed drone operator**, an **Apple Developer Program member since age 10**, and the founder of the **Syrian Speedcubing Community**.

My two companies are active and generating revenue. My code is in production. And I'm just getting started.

> *"Build first. Talk later."*

## 🚀 Notable Projects

<details open>
<summary><strong>🧠 Lumi — Adaptive AI Learning Platform</strong> · <a href="https://bit.ly/4dzujs4">Live Demo</a></summary>
<br/>

Built for students with Dyslexia, ADHD, and learning differences. One lesson upload, every learner gets it tuned to how their brain reads, in under 60 seconds. Word-synced narration, tap-to-define glossary, AI-generated imagery, Pomodoro focus mode, Quick Checks with progressive hints. Full teacher portal with audit trail. GDPR and FERPA compliant. Zero training on student data.

**Result:** 2nd Place, Safe AI Cup 2026 (Teens Track) — University of Dubai.
**Stack:** FastAPI · AWS EC2 · PostgreSQL on RDS · CloudFront + S3 · Gemini Live API · React · WebSockets

</details>

<details>
<summary><strong>🌱 GreenSteps — AI Sustainability Assistant</strong> · <a href="https://greensteps.devlix.org">Live Demo</a></summary>
<br/>

AI-powered sustainability coaching platform built end-to-end in 48 hours during a hackathon. Personalized step-by-step guidance through interactive AI-driven flows. Real-time AI with WebSocket architecture. Technical Lead on a team of 4.

**Result:** Gold Medal, Innovation Nation 2026 (Open Category) — Robotna, Arab Regional Level.
**Stack:** FastAPI · AWS EC2 · PostgreSQL · CloudFront + S3 · Gemini Live API · React · CloudWatch

</details>

<details>
<summary><strong>🧩 SpeedCubeHub Theme — Custom Shopify 2.0</strong></summary>
<br/>

Built a fully custom Shopify 2.0 theme from scratch. Bilingual EN/AR support with RTL layout switching, hero product carousel with 3D CSS effects, mega menu navigation, AJAX cart drawer with free-shipping progress bar, customer account system, geolocation currency, and full responsive design.

**Stack:** Shopify Liquid · Vanilla JS · CSS3 · Shopify Markets API

</details>

<details>
<summary><strong>🤖 SmartDesk OS — Edge-AI Productivity Hub</strong></summary>
<br/>

Arduino UNO Q x Qualcomm Hackathon 2026 project. Dual computer vision models for focus detection and posture monitoring. Physical environmental responses (lighting, alerts). Flutter companion app for real-time monitoring and analytics.

**Stack:** Arduino UNO Q · Python · LangGraph · Flutter · Firebase · CV models

</details>

<details>
<summary><strong>🔗 NEXUS — Personal AI Link Intelligence Hub</strong></summary>
<br/>

Personal knowledge management system that uses AI to analyze, categorize, and surface connections between saved links and resources. Built with Claude API for intelligent content processing.

**Stack:** Supabase · Claude API · Next.js · TypeScript

</details>

<details>
<summary><strong>🎮 ABYSS — Deep-Sea Horror Browser Game</strong></summary>
<br/>

Built for Campfire Dubai x HackClub. A browser-based horror game set in the deep sea. Progressive tension mechanics, procedural elements, and atmospheric audio design.

**Stack:** Phaser.js · JavaScript
